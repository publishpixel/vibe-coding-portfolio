## Important demo note

These are fictional portfolio concepts, not production client systems. Some buttons and interactions are front-end demonstrations. They do not provide real customer accounts, live booking inventory, payment processing, order fulfilment or persistent backend data unless explicitly stated and separately implemented.

## Run locally

Open `index.html` in a browser, or use VS Code Live Server. Each project is self-contained and can be deployed independently.
